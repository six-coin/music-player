# Music Player

本地音乐库管理器与播放器。

## 命名

| 代号 | 英文名 | 中文名 |
|---|---|---|
| manager | Music Library Manager | 音乐库管理器 |
| player | Music Player | 音乐播放器 |
| simple | Simple Music Player | 轻量音乐播放器 |

界面标题、窗口标题、文档与安装包一律使用上表的中文名；代码、目录、入口文件一律使用代号。

## 快速开始

1. 双击 `setup.bat` 安装环境（需要 [uv](https://docs.astral.sh/uv/)）。
2. 双击 `manager.bat` 打开管理器，导入歌曲、配置默认歌单。
3. 双击 `simple.bat` 直接开始播放（需要先装 [VLC](https://www.videolan.org/vlc/)）。

| 入口 | 说明 |

## 轻量音乐播放器（simple）

双击就开始播默认歌单，没有菜单、没有选择界面。所有配置都在管理器中改，simple 只读。

| 按键 | 动作 |
|---|---|
| `Ctrl+C` | 跳过当前曲，立刻换下一首，不退出 |
| `Ctrl+Q` | 退出（停止播放、恢复控制台模式） |
| `Alt+F4` | 同上；另外直接点窗口右上角 × 也是干净退出 |

- 播放模式只有两种：随机、列表循环，取管理器「轻量音乐播放器」设置页的 `simple.order`。
- 自适应按歌单独立：开关与四项参数都在歌单详情里配，全局默认值在「通用」页。界面第二行有「自适应 开/关」标识；**关掉时完全不写统计**，自动跳过是静默的，只记日志。
- 退出码：`0` 正常退出，`1` 启动失败（缺 VLC、默认歌单为空等），`2` 运行中致命错误。

## 目录

| 目录 | 说明 |
|---|---|
| `app/core` | 纯逻辑：音乐库、歌单解析、自适应、导入、换源、完整性 |
| `app/system` | 系统集成：原子写、文件锁、单实例、主题、回收站、媒体服务、VLC |
| `app/cli` | 命令行界面：控制台输入层、固定区域绘制、播放循环 |
| `app/ui/manager` | 管理器界面：三个静态文件，没有构建步骤 |
| `config/` | 运行期数据，不进版本库 |
| `assets/music/` | 入库音频，文件名即 MD5 |

## 自适应

自适应按**歌单**独立配置：每个歌单（包括内置的默认歌单）都有自己的开关与四项参数，同一首歌在不同歌单里的记录互不相干。歌曲详情显示的是「默认歌单」里的数据，其它歌单的统计在各自歌单详情的「查看统计」抽屉里。
