# 音乐播放器 使用手册

本地音乐库管理器与两个播放器：管理器负责导入、整理、配置，播放器只负责播放。Windows 桌面程序，双击即用。

[English](en-US.md)

---

## 1. 安装

需要 Windows 10 或 11，以及 [uv](https://docs.astral.sh/uv/)。其它依赖由 `uv sync` 装进项目里的 `.venv`。

```bat
setup.bat
```

双击 `setup.bat`，它会检查 uv、创建虚拟环境并安装依赖。装完窗口会停住，按任意键关闭。

| 组件               | 什么时候需要    | 说明                                   |
|------------------|-----------|--------------------------------------|
| uv               | 必装        | 只用它管理依赖，不用 pip 或 conda               |
| WebView2 Runtime | 管理器与播放器   | Windows 11 自带；Windows 10 一般随 Edge 装好 |
| VLC              | 只用轻量音乐播放器 | 装 64 位版；程序启动时会自己找                    |
| FFmpeg           | 可选        | 导入时清洗音频、读取时长；缺了不影响播放                 |

换一台机器：把程序目录拷过去，在新机器上重新跑一次 `setup.bat`；再把 `%PROGRAMDATA%\six-coin\music-player` 整个数据目录拷到同一位置，库、歌单与音频都还在。

## 2. 启动

| 入口            | 打开什么                |
|---------------|---------------------|
| `manager.bat` | 音乐库管理器（窗口）          |
| `player.bat`  | 音乐播放器（窗口，不需要 VLC）   |
| `simple.bat`  | 轻量音乐播放器（控制台，需要 VLC） |
| `setup.bat`   | 安装或更新运行环境           |

三个程序各自只允许开一个。已经开着时再双击，会提示「已经在运行了」并退出，不会出现第二个窗口。

**第一次运行**时，无论先双击哪个入口，都会打开管理器：先选界面语言（默认跟随 Windows 的系统语言，没有对应语言包就用英语；下拉框一改，界面立刻切成那种语言），再读一遍使用说明。如果先点的是 `player.bat` 或 `simple.bat`，读完说明后还会多一句提示，说明刚打开的其实是管理器。设置完成后重新双击原来的入口即可。

关掉窗口就是退出。下次打开管理器回到概览页；播放器回到上次的歌单与位置，处于暂停。

## 3. 界面

管理器是三栏：左边导航，中间列表，右边详情。

| 区域  | 放什么                      |
|-----|--------------------------|
| 导航  | 概览、歌曲、歌单、标签、作者，底部是设置     |
| 列表  | 当前分区的条目，顶部是标题、计数与新建按钮    |
| 详情  | 选中条目的编辑区，改完即保存，没有「保存」按钮  |
| 试听条 | 点「试听」后从底部升起，可以暂停、拖进度、调音量 |

概览没有列表栏，主区横跨两栏：上面是六张数据卡片（歌曲、总时长、占用、歌单、作者、标签组），中间是「最近导入 / 最近编辑」与「待处理」，下面是常用入口。

## 4. 导入音乐

只接受 `.mp3` 与 `.m4a`。其它格式会被拒绝，并说明原因。

| 操作           | 结果            |
|--------------|---------------|
| 点「导入音乐」选一个文件 | 直接开始导入，弹窗显示进度 |
| 点「导入音乐」选多个文件 | 进入批量导入向导，三步   |

批量导入向导：

| 步骤     | 做什么                       |
|--------|---------------------------|
| 1 确认信息 | 逐条改名称与作者；作者用逗号分隔；可以删掉某个文件 |
| 2 选择标签 | 给这一批统一勾选标签，可以跳过           |
| 3 开始导入 | 汇总确认，可选是否清洗音频，然后开始        |

导入规则：

- 文件名里的「歌名 - 作者1, 作者2」会被自动拆开，作者不存在时自动新建。
- 去重看内容：同一个音频文件导入第二次会跳过，失败清单里写明「与《歌名》是同一个文件（MD5 相同）」——清洗会把标签差异抹平，所以两首听着不同的文件也可能落到同一个 MD5。
- 音频按 MD5 命名存进 `assets\music\`，原文件不动。
- 清洗音频（默认开启）会用 FFmpeg 重封装并丢弃元数据。同一首歌的不同标签版本因此也能被认出是同一首。没装 FFmpeg 时导入会直接失败并提示，可以在设置里关掉这个开关。
- 单个文件失败不打断整批，最后一次性列出成功与失败。

## 5. 歌曲

列表按名称排序，可以切换成导入时间、时长、作者。搜索框同时匹配歌名、别名、作者与标签。

| 操作     | 怎么做                           |
|--------|-------------------------------|
| 选中一首   | 点一下，详情区显示它的信息                 |
| 多选     | `Ctrl` 点选、`Shift` 连选，或勾选行首复选框 |
| 批量加标签  | 多选后点「加标签」                     |
| 批量加入歌单 | 多选后点「加入歌单」，只能加入手动歌单           |
| 批量删除   | 多选后点「删除歌曲」                    |

详情卡片：

| 卡片   | 内容                                             |
|------|------------------------------------------------|
| 基本信息 | 名称、作者（可搜索添加、可上下调整顺序）、标签（按组勾选）                  |
| 文件   | MD5、路径、大小、时长、导入时间                              |
| 自适应  | 这首歌的总播放次数，以及它在默认歌单里的记录数、跳过率、完整播放次数、自动跳过次数、下次概率 |

右上角「更多」里有四个动作：

| 动作    | 说明                            |
|-------|-------------------------------|
| 试听    | 在底部试听条播放，不影响正在运行的播放器          |
| 管理别名  | 别名只用于搜索，不显示在列表里               |
| 更换源文件 | 换一个音频文件，名称、作者、标签、歌单归属与统计都留在原地 |
| 删除歌曲  | 二次确认后删除，音频文件进回收站              |

标签组可以设成「必选」与「唯一」。违反约束不会阻止保存，只在列表行上标一个琥珀色小点，由完整性检查兜底。

## 6. 歌单

两种歌单，类型在创建时确定，之后不能切换：

| 类型 | 收歌方式           |
|----|----------------|
| 手动 | 自己挑歌，顺序可拖拽调整   |
| 条件 | 按规则自动收歌，改动即时重算 |

另有一个内置的「默认歌单」，包含全部歌曲，不可删除、不可改名。轻量音乐播放器播的就是它。

条件歌单的每一行是「包含/排除 · 对象 · 取值」：

| 对象   | 取值                       |
|------|--------------------------|
| 全部歌曲 | 无                        |
| 歌曲   | 从库里挑                     |
| 歌单   | 挑另一个歌单（可以嵌套，出现循环引用时该行标红） |
| 标签   | 挑标签，命中任一即算               |
| 作者   | 挑作者，命中任一即算               |

条件按从上到下的顺序求值：包含做并集，排除做差集。空条件的命中数是零。

每一行左边有一个把手，按住它上下拖就能改条件的先后顺序。

歌单列表可以拖拽排序：按住一行拖到目标位置松手，顺序会写进 `playlists.json`，播放器的歌单栏也跟着变。

歌单详情的「自适应」卡片是该歌单自己的配置；「查看统计」从右侧滑出抽屉，列出每首歌的记录数、跳过率、总播放次数、完整播放次数、自动跳过与下次概率。抽屉里每行右边有一个「清空」，点了会先问一句——再小的数据点下去就没了。

删除歌单：内置歌单不可删；被其它条件歌单引用的，会先把引用方全部列出来（多了就在框里滚动），处理掉引用后才能删。

## 7. 标签与作者

标签组是分类的容器，组里放标签。两个开关：

| 开关 | 含义               |
|----|------------------|
| 必选 | 每首歌至少要有一个这组里的标签  |
| 唯一 | 每首歌最多只能有一个这组里的标签 |

标签组列表可以拖拽排序；组里的小标签在输入框左边有一个把手，按住它上下拖就能改顺序，松手即保存。

作者有名称与简介。作者列表按名称排序，不能手动调整；歌曲详情里的作者选择器用同一个顺序。没有任何作品的作者可以一键清理。

删除被引用的作者或标签组时，会先列出受影响的歌曲；确认之后连同引用一起移除。

## 8. 自适应

自适应是「后台帮你过滤不喜欢的歌」。它按**歌单**独立配置：每个歌单都有自己的开关与四项参数，同一首歌在不同歌单里的记录互不相干。

| 参数   | 默认  | 范围      | 含义                 |
|------|-----|---------|--------------------|
| 记录窗口 | 100 | 10–1000 | 每首歌保留最近多少次播放       |
| 免跳次数 | 10  | 0–窗口    | 记录不足这个数时一定不跳过      |
| 跳过基数 | 95% | 1–99%   | 概率上限系数             |
| 跳过阈值 | 30  | 5–300 秒 | 播放不足这个秒数就切歌，记为一次跳过 |

判定公式（对「歌单 P 中的歌 M」）：

```
n = 已有记录条数
s = 其中跳过的条数
n <= 免跳次数  → 不跳过
否则          → 概率 = min(基数, 0.99) × s / n，按这个概率跳过
```

记录规则：

| 情形                       | 记录              |
|--------------------------|-----------------|
| 在阈值内主动切歌（下一首 / `Ctrl+C`） | `1`             |
| 播过阈值后切歌                  | `0`，完整播放 +1     |
| 自然播完                     | `0`，完整播放 +1     |
| 自动跳过                     | 不记录，只累加「自动跳过」次数 |
| 上一首、点队列、切歌单、退出程序         | 不记录             |

「完整播放」是每首歌在**这个歌单**里播够阈值、没被切走的次数，只用于展示（歌单详情的统计抽屉里能看到），不参与判定。

「总播放」是另一套账：**全库一份**，不按歌单分，清空自适应也不会清掉它。能关掉它的只有设置「通用 → 播放记录 → 记录歌曲总播放次数」这一个开关——歌单的自适应关掉、调试状态打开，它都照样记。判定标准看当时正在播的环境：在歌单里播用那个歌单的跳过阈值，单曲循环用全局阈值；自然播完永远算一次。

自动跳过是**静默**的：不弹提示、不闪警告，界面直接换下一首，只在队列里把这首标成已播。

设置页「音乐库管理器 → 维护 · 调试状态」打开时，两个播放器都不再判定也不记录，方便排查问题。

## 9. 音乐播放器

窗口三栏：左边歌单，中间当前这首，右边待播队列。所有设置都在管理器里改，播放器只读。

中间是一张歌曲卡片：卡片顶部写着当前歌单，旁边一枚徽标说明这个歌单有没有开自适应（「自适应 开」/「自适应 关」，鼠标停上去有解释；调试状态打开时徽标会说明它暂时不生效），下面才是歌名、作者、进度、控件与音量。窗口拉大时卡片居中、内容跟着居中，空白落在卡片外面，而不是散在字与字之间。

| 行为        | 说明                          |
|-----------|-----------------------------|
| 点歌单       | 载入并从第一首开始播                  |
| 再点一次当前歌单  | 什么都不做，进度与队列都不动              |
| 点队列里的歌    | 立刻切过去，从 0 开始；已播的也可以点回去      |
| 上一首 / 下一首 | 到头时按模式处理，不会停                |
| 三种模式      | 随机、列表循环、单曲循环，都是无尽的          |
| 单曲循环选歌    | 曲名旁的「选一首循环」可以从全部曲目里挑，不必先切歌单；任何模式下按 `Ctrl+L` 也能打开这个弹窗，选完自动切到单曲循环 |

待播队列永远是**整张歌单**：已播的灰、正在播的高亮、待播的正常。最后一首播完才生成下一轮，进入新一轮后「上一首」禁用。

关掉窗口就是退出。下次打开停在原处，处于暂停，按播放继续。音量、模式、窗口尺寸、队列开合都会记住。

## 10. 轻量音乐播放器

双击就开始播默认歌单，没有菜单、没有选择界面。所有配置都在管理器里改，它只读。

控制台里是一个方框：歌名、作者、所属歌单与「第 N / M 首」、播放模式、自适应开关，最后一行是按键提示——提示里写的就是当前绑定的键。

| 行为   | 说明                                 |
|------|------------------------------------|
| 播放模式 | 只有随机、列表循环，取管理器「轻量音乐播放器」页的设置        |
| 音量   | 程序不设音量，用 VLC 自己记住的那个值；要调就在系统混音器里调  |
| 跳过   | 默认 `Ctrl+C`，立刻换下一首，不退出（可在设置里改）     |
| 退出   | 默认 `Ctrl+Q`（可在设置里改）；`Alt+F4` 与点窗口右上角 × 始终是干净退出 |
| 自适应  | 按默认歌单的配置判定与记录，界面上只显示开关状态           |
| 界面语言 | 跟随管理器设置的语言，启动时读一次                  |

控制台读得到哪些键是有限制的：只有 `Ctrl+` 一个字母、空格、回车、Tab、Esc 与退格。设置页里录别的组合会被挡下，手改设置文件写了读不到的组合，启动时退回出厂键并在日志里记一条。

退出码：`0` 正常退出，`1` 启动失败（没装 VLC、默认歌单为空等），`2` 运行中致命错误。

## 11. 完整性检查

概览的「待处理」和设置页「音乐库管理器 → 维护」都能进。快速检查不读音频内容，深检会把每个文件重算一遍 MD5，再用 ffprobe 核一遍码率，按文件大小显示进度，可以中途取消。

| 类别   | 检查什么                                          | 能否自动修复      |
|------|-----------------------------------------------|-------------|
| 文件缺失 | 记录在、`assets\music` 里没有对应文件                    | 否，需要重新导入或换源 |
| 孤儿文件 | 文件在、库里没有记录                                    | 能，送进回收站     |
| 内容不符 | 深检发现文件内容与记录的 MD5 不一致                          | 否           |
| 规格虚标 | 深检发现文件头声明的码率远高于「文件大小 ÷ 时长」算出的实际码率，或歌名标称的码率对不上 | 否，换一个来源     |
| 失效引用 | 歌曲引用了不存在的作者或标签，歌单引用了不存在的对象                    | 能，摘掉失效引用    |
| 标签约束 | 必选组为空、唯一组多选                                   | 否，跳到那首歌自己改  |
| 统计残留 | 统计文件里有库里已经不存在的歌                               | 能，按当前库清理    |

修复按类别执行，也可以一次修全部可自动处理的。这几类都是「删掉已经没有对应实体的数据」，所以修复前不再二次确认；孤儿文件进的是回收站，可以还原。

## 12. 快捷键

只在窗口（或控制台）处于前台时生效，不抢系统与其它程序的按键。

下面列的是**出厂值**。三端的按键都能在管理器的设置页里改：管理器、轻量音乐播放器、音乐播放器各自的分页里都有一张「快捷键」卡片。`Ctrl+C`、`Ctrl+V` 这类系统默认的编辑按键、以及弹窗里的 `Esc` / `Tab`，不参与自定义。

音乐播放器：

| 按键                  | 动作              |
|---------------------|-----------------|
| `Space`             | 播放 / 暂停         |
| `←` / `→`           | 快退 / 快进 5 秒     |
| `Ctrl+←` / `Ctrl+→` | 上一首 / 下一首       |
| `↑` / `↓`           | 音量 ±5%          |
| `Ctrl+C`            | 跳过当前歌（等价于「下一首」） |
| `Ctrl+L`            | 打开单曲循环选歌弹窗      |
| `Esc`               | 收起队列            |

轻量音乐播放器：

| 按键       | 动作    |
|----------|-------|
| `Ctrl+C` | 跳过当前曲 |
| `Ctrl+Q` | 退出    |
| `Alt+F4` | 退出    |

`Alt+F4` 与 `F4` 是固定的逃逸出口，改了跳过 / 退出键也仍然有效。

管理器：`Ctrl+F` 聚焦搜索框、`Ctrl+I` 导入音乐、`Ctrl+,` 打开设置。`Esc` 关闭弹窗、抽屉或右键菜单，`Tab` 在弹窗内循环——这两类属于控件的默认交互，不参与自定义。没有 `Ctrl+S`——所有改动都是即时保存。

## 13. 设置

五个分页，改完即生效，没有保存按钮。

| 分页      | 内容                                                                                  |
|---------|-------------------------------------------------------------------------------------|
| 通用      | 主题（浅色 / 深色，没有「跟随系统」）、语言（按语言代码排序）、自适应默认值（记录窗口、免跳次数、跳过基数、跳过阈值）、播放记录（记录歌曲总播放次数）        |
| 音乐库管理器  | 试听默认音量、导入（默认目录、导入时清洗音频、FFmpeg 与 ffprobe 状态）、维护（完整性检查、清理孤儿文件、清空自适应统计、打开数据与日志目录、调试状态）、快捷键 |
| 轻量音乐播放器 | 播放模式、默认歌单（只读，可跳转）、快捷键                                                              |
| 音乐播放器   | 默认音量、播放模式、记住播放进度、快捷键                                                               |
| 关于      | 数据目录（输入框 +「更改」「重置」）、使用说明、重置所有设置、版本                                                  |

跳过基数是 1–99 的百分比：实际跳过概率 = 基数 × 这首歌最近一段时间的跳过比例。

改快捷键：点一下那个按键帽，它变成「按下按键…」，接着按下新的组合键即可；只按修饰键不算，按 `Esc` 取消。同一页里两个动作不能共用同一个键，撞了会提示是哪一个占着；每行右边的「恢复默认」只改那一行，卡片底部的「恢复本页默认」一次改回全部。控制台那页只收 `Ctrl+字母`、空格、回车、Tab、Esc 与退格，别的组合会被挡下并说明原因。

语言切换立刻生效：界面文案、窗口标题、排序下拉框一起换。音乐播放器与轻量音乐播放器在启动时读一次语言与快捷键，改了要重开才跟着变。

「重置所有设置」会把语言与外观一起恢复默认，音乐库、歌单与统计不受影响。改数据目录会自动补上 `music-player` 这一层，重启后生效并把旧内容（含音频）搬过去；目标已有的同名文件不覆盖。

## 14. 文件与目录

程序目录只放代码与随程序分发的示例音频；运行期文件全在系统目录里。

```
Music Player\
├─ manager.bat / player.bat / simple.bat / setup.bat
├─ manager.pyw / player.pyw / simple.py      入口薄壳
├─ app\                                      全部代码
│  ├─ core\                                  纯逻辑
│  ├─ system\                                系统集成
│  ├─ cli\                                   轻量音乐播放器的界面
│  ├─ ui\manager\                            管理器界面
│  ├─ ui\player\                             播放器界面
│  └─ locales\                               语言包
├─ assets\                                   随程序分发的示例音频
├─ docs\                                     文档
└─ tests\                                    测试

%PROGRAMDATA%\six-coin\music-player\         数据目录（可更改）
├─ settings.json                             设置
├─ library.json                              作者、标签组、歌曲
├─ playlists.json                            歌单与默认歌单
├─ player.json                               播放器窗口尺寸、队列开合
├─ stats\<歌单标识>.json                       每个歌单一份自适应统计
├─ totals.json                               歌曲级总播放次数（全库一份）
└─ music\<md5>.<ext>                          入库音频，文件名就是 MD5

%LOCALAPPDATA%\six-coin\music-player\

├─ locks\                                    锁
```

日志按启动时间命名，单文件超过 5 MB 轮转，保留 14 天。排查问题时先看最新的那份。数据目录的最后一层恒是项目代号：选 `D://Data` 得到 `D://Data//music-player`。

## 15. 常见问题

**双击 bat，黑框一闪就没了。** 运行环境还没装好。先跑 `setup.bat`；如果它也说找不到 uv，按提示装 uv 再重试。

**提示「管理器已经在运行了」。** 同一个程序只允许开一个。切到任务栏找已经开着的窗口；找不到就用任务管理器结束残留进程。

**导入时提示不支持的格式。** 只收 `.mp3` 与 `.m4a`。其它格式需要先自行转码。

**导入时提示未检测到 FFmpeg。** 清洗音频要用 FFmpeg。装上并加入 `PATH` 后，在设置「音乐库管理器 → 导入」里点「重新检测」；或者直接关掉「导入时清洗音频」。

**播放器打开了但没有声音。** 先看队列里那首是不是标了「文件缺失」——文件被移走或改名了。文件还在的话，检查系统音量与播放器右下角的音量。

**换了主题，播放器没变。** 播放器只在启动时读主题与语言，关掉重开。

**换源时提示「这个文件已经是库里的《…》」。** 新文件的内容与库里另一首歌完全相同。先处理那一首（换源或删除），再回来换。

**删掉的歌还能找回来吗？** 能。音频文件在回收站里，名字就是歌名。恢复之后还需要重新导入。

**界面变成了英文。** 设置「通用」页的语言切回了 English，切回「简体中文 (中国)」即可。

## 16. 已知限制

- 只支持 Windows。回收站、单实例、控制台输入都直接调用 Windows API。
- 不做封面、歌词、频谱可视化。
- 不做硬件媒体键与全局热键，三个程序都只响应自己窗口内的按键。
- 不做音频转码。清洗只是重封装，不改变编码参数。
- 播放器不热加载：管理器里新导入的歌、改过的歌单，要重启播放器才出现。
- 播放器关闭时最多丢 2 秒播放位置（关闭回调里不等网页回话，避免死锁）。
- 轻量音乐播放器没有暂停、音量调节、进度条，也不能切歌单。
- 不做多用户、同步、云备份。
- 语言只出简体中文与英文两份；异常路径（崩溃弹窗、日志、完整性报告）固定中文。
